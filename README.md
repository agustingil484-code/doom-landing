# DOOM 1993 · Landing page

Landing page hecha con React + Vite para el Curso Intensivo de Vibe Coding con React.
Permite jugar al episodio shareware original de DOOM (1993) directo en el navegador.

## Cómo correrlo

```bash
npm install
npm run dev
```

Después abrí la dirección `http://localhost:5173` que muestra la terminal.

## Créditos

- DOOM es una marca de id Software.
- El juego se carga desde [Internet Archive](https://archive.org/details/DoomsharewareEpisode), que aloja el episodio shareware y lo emula en el navegador.
